# Credits

Marble Rush is an original game. The track, the toy room, the marbles and the start screen are built in code. No personal names here (G1.11).

## Music

- The title track is the driving starter's stand-in, made by `tools/make_starter_audio.py`. It is replaced when BC picks a Patch.gg track.

## Made for this game

- Marble sounds (clack, the gate, the finish fanfare and the rolling loop) made by `tools/make_marble_sfx.py`.
- The app icon, drawn in code (`icon_src/`).

## Tools

- Godot Engine 4.7. https://godotengine.org (MIT licence)
